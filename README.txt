LANDING PAGE NEXOSHOP

ARCHIVOS
- index.html: estructura y contenido.
- styles.css: diseño adaptable a celulares, tablets y computadores.
- script.js: selección de talla y pedido por WhatsApp.
- assets/tenis-nexoshop.jpeg: fotografía que compartiste.

CÓMO USARLA
1. Descomprime la carpeta/ZIP.
2. Abre script.js y cambia WHATSAPP_NUMBER por el número real de tu tienda.
   Usa el código de país y solo números. Colombia: 57 + número. Ejemplo: 573001234567.
3. Abre index.html en tu navegador para probarla.
4. Para publicarla, sube toda la carpeta conservando la estructura de archivos a tu hosting (por ejemplo, Netlify, Vercel o tu hosting habitual).

PERSONALIZACIÓN
- El producto, textos, preguntas y secciones se editan en index.html.
- Colores y estilos se editan al inicio de styles.css, en :root.
- Las tallas de ejemplo están entre 36 y 44; ajusta las opciones del select según tu inventario.
- El precio se muestra como “Consulta el precio” para no publicar un valor no confirmado.

IMPORTANTE
El botón abre WhatsApp con un mensaje preparado. Debes reemplazar el número de demostración antes de publicar.
